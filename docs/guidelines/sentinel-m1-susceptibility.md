M1 is a static susceptibility model (slope, lithology, landcover, distance-to-road, curvature). Scores 0–1, updated quarterly from GSI inventory. It feeds M2 dynamic risk. Zones: very_low <0.2 < low <0.4 < moderate <0.6 < high <0.8 < very_high. Q4 2023 refresh added Gangtok Valley anthropogenic cut-slope factor. Use M1 for long-range planning, not real-time alerts.
